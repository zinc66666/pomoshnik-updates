# Помощник — обновления

Подписанные обновления личной программы «Помощник» для одного ноутбука на Windows.

- `manifest.json` — номер версии, что нового, SHA-256 каждого файла.
- `manifest.sig` — подпись `manifest.json` (RSA-3072, SHA-256). Закрытый ключ хранится только у владельца.
- `releases/<версия>/` — файлы версии. Программа ставит их, только если подпись и все хэши совпали.
